# Modern Matric Higher Secondary School

Responsive React Native / Expo website for Modern Matric Higher Secondary School, Cuddalore. It uses the six school photographs supplied in `assets/`, a gallery, scroll-reveal and hero animations on web, a click-to-call link, and an embedded Google map with directions.

## Run the app

```sh
npm install
npm run web
```

`preview.html` is a standalone visual preview of the same design. The map embed does not need a Google Maps API key. The React Native project uses local school photos so they are bundled with the app rather than fetched from image sites.
